# Agent V3 Tasks

This folder stores task-level working notes.

Use `agent_v3/V3_MEMORY.md` for long-term project memory and architecture decisions. Use this folder for the current or recent implementation tasks so work can resume after context compaction.

## Rules

- Create or update a task file when a new non-trivial task starts.
- Keep each task file focused on one task or tightly related task cluster.
- Record the user request, agreed constraints, files touched, current status, verification commands, and known follow-ups.
- Do not put broad project history here; summarize durable decisions back into `V3_MEMORY.md` when they become project-level rules.
- Do not read old task files proactively unless they are relevant to the current task or the user asks.

## Suggested Format

# Task: short-name

Updated: YYYY-MM-DD
Status: planned | in_progress | blocked | done
